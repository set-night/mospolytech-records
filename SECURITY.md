# Безопасность

Если вы нашли уязвимость, пожалуйста, **не открывайте публичный issue**. Сообщите приватно через
[GitHub Security Advisories](https://github.com/set-night/mospolytech-records/security/advisories/new).
Мы ответим в течение недели.

Исправления выходят только для последней версии — обновляйтесь, когда приложение об этом сообщит.
